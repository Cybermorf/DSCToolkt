# Multiclass (v next)

Character sheets support PHB multiclassing:

- Multiple class rows (class + level + subclass)
- Character level = sum of class levels
- Proficiency bonus from **total** level (epic PB continues past 20)
- Spell slots use the **multiclass caster table** (full + half + 1/3 casters; Warlock pact slots separate)
- Ability score prerequisites checked for secondary classes
- Levels **above 20** allowed (DM option), spell slot table still caps at 20th-level progression

Deploy the latest `DSCToolkt-app.zip` over the static site (large JS).
